# Prompt (shu landing pageni qayta yaratish uchun)

Menga IT talabasi **Hanifaxon Umarova** uchun creative portfolio landing page yarat.

**Texnologiya:** faqat HTML, CSS, vanilla JavaScript. Fayl tuzilmasi: `index.html`, `css/style.css`, `js/main.js`, `js/i18n.js`, `images/` (profile.jpg + project1-3 placeholder rasmlar, men keyin o'zimnikiga almashtiraman).

**Rejimlar:** Dark va Light tema (tugma bilan almashadi, localStorage'da saqlanadi, tizim temasini hisobga oladi). Ikki til: UZ va EN (data-i18n kalitlari + alohida i18n.js, tanlov saqlanadi).

**Dizayn:** palitra profil rasmidan olingan — chuqur o'rmon yashili, och yashil, karamel-jigarrang aksent. Sarlavhalar uchun Unbounded, matn uchun Manrope. Esda qoladigan asosiy element: profil rasmi kamar (arch) shaklida, atrofida aylanuvchi yozuv halqasi va suzuvchi kod chiplari (<html/>, { css }, js(), git).

**Bo'limlar:** Hero (ism, yozilib turuvchi rollar, CTA tugmalar), Men haqimda (kod ko'rinishidagi JS obyekt), Ko'nikmalar (scrollda to'ladigan progress bar), Loyihalar (3 ta 3D tilt kartochka), Aloqa (email + Telegram/GitHub/LinkedIn), footer.

**Qo'shimcha:** kursor ortidan yuruvchi yorug'lik, sticky shaffof navbar, mobil moslashuv, klaviatura focus ko'rinishi, prefers-reduced-motion hurmat qilinadi. Tayyor kod har bir fayl uchun alohida bo'lsin.
